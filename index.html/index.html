MySQL Training (Database Schema + Sample Data)

This section demonstrates typical MySQL tables for a Safaricom-like system using HTML only. It does not connect to a database.

Schema Overview

  • customers: user profiles (MSISDN, name, email)
  • services: supported services (Airtime, Bundles, M-Pesa)
  • bundles: data bundles catalog
  • transactions: payment and top-up records
  • faqs: FAQ content

Tables

Example tables (training)
Table Primary key Typical columns
customers customer_id full_name, msisdn, email, country_code
services service_id service_name, service_code, description
bundles bundle_id bundle_name, validity_days, price_kes, data_gb
transactions transaction_id customer_id, service_id, amount_kes, status, created_at
faqs faq_id question, answer, category
