# AMPATH Management System (MVP)

## Executive Summary
The **AMPATH Management System** is a centralized digital healthcare and organizational management platform designed to support patient care, hospital administration, research, internship/attachment management, incident reporting, finance, procurement, training, analytics, and community outreach.

The **MVP (Minimum Viable Product)** focuses on core hospital operations:
- Patient portal
- Staff portal
- Appointments
- Incident reporting
- Internship management
- Role-based dashboards

The **full enterprise version** expands into:
- AI-powered analytics
- Research workflows
- Predictive healthcare insights
- Mobile applications
- Advanced BI reporting
- Integrated e-learning

The goal is to improve healthcare efficiency, transparency, accountability, data-driven decision-making, and service delivery across all AMPATH facilities.

## MVP scope (Phase 1)
- Authentication
- Patient portal: dashboard + appointments
- Staff portal: dashboard + incident inbox
- Incident reporting: create incident + SLA tracking + evidence upload validation
- Internship portal: apply + document upload validation

## Planned stack
- Frontend: React (HTML/CSS/JavaScript)
- Backend: Python REST API (FastAPI)
- DB: PostgreSQL
